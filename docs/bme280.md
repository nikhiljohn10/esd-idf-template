# bme280

I2C driver for the Bosch **BME280** temperature, pressure and humidity sensor (ESP-IDF 5.x `i2c_master` API).

**Header:** `lib/bme280/bme280.h`

---

## Overview

Self-contained driver for any BME280-compatible breakout (e.g. 7SEMI ES-13528, Adafruit, generic GY-BME280). On `bme280_init()` the driver:

1. Obtains (or creates) the shared `i2c_master` bus for the requested port via the `i2c_bus` library.
2. Auto-detects the sensor at `0x76` or `0x77` and verifies chip-id `0x60`.
3. Issues a soft reset, waits for the NVM copy to complete.
4. Reads all factory calibration coefficients.
5. Configures the _weather-monitoring_ profile (forced mode, x1 oversampling on T/P/H, IIR filter off — datasheet §3.5.1).

Each call to `bme280_read()` triggers one forced-mode measurement and returns compensated values.

> Only one sensor instance is supported (driver state is held in a `static` context).

## API

### `bme280_config_t`

```c
typedef struct {
    i2c_port_num_t i2c_port; // I2C peripheral, e.g. I2C_NUM_0
    int sda_pin;             // GPIO for SDA
    int scl_pin;             // GPIO for SCL
    uint32_t freq_hz;        // I2C clock (max 400 000)
} bme280_config_t;
```

### `bme280_data_t`

```c
typedef struct {
    float temperature;  // °C
    float pressure;     // hPa
    float pressure_bar; // bar
    float humidity;     // %RH
} bme280_data_t;
```

### `esp_err_t bme280_init(const bme280_config_t *config, bme280_data_t **data)`

Creates the I2C bus, detects the sensor, reads calibration and configures the device.
Allocates a `bme280_data_t` internally (via `calloc`) and writes the pointer to `*data`.

Returns `ESP_OK` on success or any `i2c_master`/`ESP_ERR_*` code on failure.

```c
bme280_config_t cfg = {
    .i2c_port = I2C_NUM_0,
    .sda_pin  = GPIO_NUM_21,
    .scl_pin  = GPIO_NUM_22,
    .freq_hz  = 100000,
};
bme280_data_t *s = NULL;
ESP_ERROR_CHECK(bme280_init(&cfg, &s));
```

### `esp_err_t bme280_read(bme280_data_t *data)`

Triggers a single forced-mode measurement (~10 ms), then burst-reads and compensates pressure, temperature and humidity. Returns `ESP_ERR_INVALID_STATE` if `bme280_init()` has not been called.

```c
if (bme280_read(s) == ESP_OK) {
    printf("T=%.2f C  P=%.2f hPa  RH=%.1f %%\n",
           s->temperature, s->pressure, s->humidity);
}
```

### `float get_vpd(float temp_c, float hum_percent)`

Calculates vapor pressure deficit from air temperature and relative humidity.

- Uses the Tetens formula to compute saturation vapor pressure.
- Returns VPD in kilopascals (kPa).
- Useful for assessing plant stress and evaporation potential.

```c
float vpd = get_vpd(s->temperature, s->humidity);
printf("VPD: %.3f kPa\n", vpd);
```

### `float get_vapor_pressure(float temp_c, float hum_percent)`

Calculates the current vapor pressure from temperature and relative humidity.

- Returns actual vapor pressure in kilopascals (kPa).

```c
float vapor = get_vapor_pressure(s->temperature, s->humidity);
printf("Vapor pressure: %.3f kPa\n", vapor);
```

### `float get_dew_point(float temp_c, float hum_percent)`

Calculates the dew point temperature using the Magnus-Tetens approximation.

- Returns dew point in degrees Celsius.

```c
float dew_c = get_dew_point(s->temperature, s->humidity);
printf("Dew point: %.2f C\n", dew_c);
```

### `float get_humidex(float temp_c, float hum_percent)`

Calculates the Canadian humidex index from temperature and humidity.

- Returns the apparent temperature in degrees Celsius.

```c
float humidex = get_humidex(s->temperature, s->humidity);
printf("Humidex: %.2f C\n", humidex);
```

### `float get_absolute_humidity(float temp_c, float hum_percent)`

Calculates the mass of water vapor per cubic meter of air.

- Returns absolute humidity in grams per cubic meter (g/m^3).

```c
float ah = get_absolute_humidity(s->temperature, s->humidity);
printf("Absolute humidity: %.2f g/m3\n", ah);
```

### `float get_enthalpy(float temp_c, float hum_percent, float pressure_hpa)`

Calculates the specific enthalpy of moist air from temperature, relative humidity, and pressure.

- Pressure is passed in hPa.
- Returns enthalpy in kJ/kg of dry air.

```c
float h = get_enthalpy(s->temperature, s->humidity, s->pressure);
printf("Enthalpy: %.2f kJ/kg\n", h);
```

### `float get_heat_index(float temp_c, float hum_percent)`

Calculates the apparent temperature from air temperature and relative humidity.

- Uses the NOAA heat index formula with Celsius input.
- Returns the heat index in degrees Celsius.
- For temperatures below 80 °F (26.7 °C), the function returns the actual air temperature.

```c
float hi_c = get_heat_index(s->temperature, s->humidity);
printf("Heat index: %.2f C\n", hi_c);
```

## Wiring

| BME280 pin | ESP32 pin (default in examples) |
| ---------- | ------------------------------- |
| VCC        | 3V3                             |
| GND        | GND                             |
| SDA        | GPIO 21                         |
| SCL        | GPIO 22                         |

Most breakouts have built-in pull-ups; the driver also enables the ESP32 internal pull-ups as a safety net.

## Example — periodic environment logging

```c
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "bme280.h"
#include "utils.h"

void app_main(void) {
    bme280_config_t cfg = {
        .i2c_port = I2C_NUM_0,
        .sda_pin  = GPIO_NUM_21,
        .scl_pin  = GPIO_NUM_22,
        .freq_hz  = 100000,
    };
    bme280_data_t *s = NULL;
    ESP_ERROR_CHECK(bme280_init(&cfg, &s));

    while (1) {
        if (bme280_read(s) == ESP_OK) {
            printf("%.2f C  %.2f hPa  %.1f %%RH\n",
                   s->temperature, s->pressure, s->humidity);
        }
        delay(2000);
    }
}
```

See [`examples/bme280_weather/`](../examples/bme280_weather/) for an end-to-end demo that displays readings on the OLED.

## Notes

- The driver uses **forced mode** — the sensor stays in sleep between calls, which is ideal for battery-powered weather logging.
- Pressure is reported in **hPa** (hectopascals = millibars). Multiply by 100 to get Pa.
- For higher accuracy or fast-changing environments, modify `REG_CTRL_HUM`, `REG_CTRL_MEAS` and `REG_CONFIG` writes inside `bme280_init()` to enable higher oversampling or the IIR filter (datasheet §3.5).
- Do **not** call `i2c_new_master_bus` separately on the same port — the driver owns the bus.
